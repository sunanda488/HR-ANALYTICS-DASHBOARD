# HR-ANALYTICS-DASHBOARD
Developed an interactive HR Analytics Dashboard using Power BI to analyze employee data, attrition rates, workforce distribution, salary slabs, gender, age groups, job roles, and job satisfaction. Created KPIs and interactive visualizations to identify workforce trends and support data-driven HR decisions.
# HR Analytics Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing HR employee data using Microsoft Power BI. The interactive dashboard provides insights into employee attrition, workforce distribution, salary slabs, job roles, employee demographics, and job satisfaction. It helps understand employee turnover patterns and supports data-driven HR decision-making.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Visualization
- HR Data Analytics

## 📊 Key Performance Indicators (KPIs)
- **Total Employees:** 1,419
- **Active Employees:** 1,186
- **Attrition Count:** 233
- **Attrition Rate:** 16.4%
- **Average Employee Age:** 36.93
- **Average Years of Experience:** 7.04

## 📈 Dashboard Features

### 1. Employee Overview
- Total and active employee count
- Employee attrition rate and count
- Average employee age
- Average years of experience

### 2. Employee Attrition Analysis
- Department-wise attrition
- Salary slab-wise attrition
- Gender-wise attrition
- Job role-wise attrition
- Job satisfaction analysis

### 3. Workforce Analysis
- Age group distribution
- Department-wise employee count
- Attrition trends based on employee experience

### 4. Interactive Filters
- Department slicer
- Age slicer
- Interactive charts and visualizations

## 🎯 Project Objectives
- Analyze employee attrition patterns.
- Understand workforce distribution across departments.
- Explore the relationship between salary slabs and attrition.
- Analyze employee demographics and job satisfaction.
- Present HR metrics through an interactive dashboard.

## 💡 Key Learnings
- Creating interactive dashboards using Power BI.
- Designing KPI cards and data visualizations.
- Analyzing HR metrics and employee attrition.
- Using slicers and filters for interactive reporting.
- Presenting data insights through visual storytelling.
